## 현재 결과

코드는 `payload-lab`의 `codex/focused-learning-workbench` 브랜치에 저장했습니다. 주요 구현 커밋은 `71b823a`, 반복 실행 초점 보완은 `3e3e9bd`입니다. 팀 저장소 `-PayloadLab-`에는 이슈·문서·CSV를 관리합니다.

## 확인한 검증과 한계

- 백엔드 `python -m pytest backend/tests -q`: 47개 통과.
- 프론트엔드 Vitest: 25개 통과. Enter 실행→관찰 공간·초점, Shift+Enter 줄바꿈, IME·키 반복 방지, Esc 확인/취소, 유형 변경 초기화·과거 시도 불러오기 포함.
- 프론트엔드 프로덕션 빌드 통과. 로컬 Vite에서 최신 App/InputDock 모듈 제공 확인.
- 데이터 CSV: 137행(공격 시도 101, 자체 정상 32, 문맥 미정 4). 원문 파일 10개의 SHA-256을 고정 커밋과 대조했고, GitHub에서 새로 clone한 브랜치에서도 무결성·재생성 테스트 7개 통과.
- 브라우저 조작이 비활성화되어 이번 최종 화면의 시각 배치를 직접 확인하지 못함.
- 실제 사용자 학습 효과, AI 학습 정확도, 외부 공격 성공, 운영 배포·보안 점검 완료를 주장하지 않음.
