# UX-03 터미널 입력면

기준: `09142b0`. 상태는 WORK-STATE에서만 관리한다. UX-02 자동 검사는 통과했고 브라우저 검증은 도구 비활성화로 대기 중이다.

- Linux 퀴즈·권한 입력은 TerminalInput으로 분리한다. 기존 form·Enter/Shift+Enter·IME 보호·API 필드와 2000자 상한은 재사용한다. SQL/HTML/ID/URL 편집기는 유지한다. CMDi 전용 연결은 UX-07에서 다룬다.
- 프롬프트와 네이티브 textarea를 같은 글꼴/기준선으로 배치한다. 한 줄에서 시작하고 긴 입력은 제한 높이까지 확장한다. 편집기 라이브러리는 추가하지 않는다.
- textarea와 같은 크기·줄바꿈·스크롤을 쓰는 비상호작용 장식 면에서 알려진 입력 범위만 밑줄로 표시한다. 실제 선택/복사/입력은 textarea가 담당한다. 키보드/터치로 읽는 진단 단추는 편집 필드 밖에 둔다.
- Permission denied가 반환되고 원문의 파일 경로와 `cat 경로`가 정확히 일치할 때만 입력 경로를 같은 진단에 연결한다. 이는 **권한 검사 대상**이며 명령 오타가 아니다. 입력 수정/분석 중에는 이전 결과의 밑줄을 표시하지 않는다.
- TDD: 실제 범위·유니코드·원문 보존, 장식과 입력의 스크롤 동기화, 폼 단축키/IME 재사용, 이전 결과 분리 순서로 실패 확인 후 구현한다. 회귀 검사와 빌드는 같은 제한 컨테이너에서 순차 실행한다.
- 실제 브라우저의 줄바꿈·200% 확대·IME·스크롤·라이트/다크는 별도 확인한다. 도구가 비활성화된 동안 완료로 체크하지 않는다.
