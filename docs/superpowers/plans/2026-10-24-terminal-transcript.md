# UX-04 명령·출력 기록

기준 `f9300e5`. WORK-STATE가 진행 상태를 관리한다.

1. TerminalTranscript는 App의 현재 랩 시도 목록을 읽는다. API·실습 history 재생·성공 판정·40개 저장 상한은 변경하지 않는다. 미지원 명령도 화면에는 남기며 백엔드 재생에서 제외하는 기존 기준을 유지한다.
2. 각 시도의 실행 전 prompt, 입력 원문, stdout/stderr, 종료 코드와 교육 해설을 분리한다. 관리자로 전환한 명령의 prompt에는 실행 전 사용자를 표시한다.
3. 선택한 시도의 진단만 현재 Lens로 연결한다. 나머지 오류는 원래 시도의 요약만 제공한다. 입력이 바뀌었을 때도 이전 기록을 새 입력의 해설로 취급하지 않는다.
4. 기존 PracticeSimulation의 사용자/권한/처리 흐름은 유지하고 원문 출력 카드만 공통 기록으로 바꾼다. CMDi 전용 콘솔 연결은 UX-07에서 진행한다.
5. TDD로 복수 시도 순서·원문 줄바꿈·실행 전 prompt·현재/과거 진단·분석 제외·HTML 텍스트 처리를 검증한다. 전체 검사와 build는 순차 실행한다. 실제 스크롤/가독성은 브라우저 검증 대기로 남긴다.
