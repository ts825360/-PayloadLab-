# 브랜드 원본 확인

연결: [통합 학습 공간 승인 범위](../decisions/2026-10-23-unified-workspace.md)

2026-10-23 현재 저장소의 파일과 상위 로컬 작업 공간에서 `logo` 이름, SVG·PNG·ICO를 조사했으나 팀이 제공한 로고 원본 자산은 찾지 못했습니다. 의존성·빌드 산출물의 이미지는 팀 로고 원본으로 취급하지 않았습니다.

현재 화면의 브랜드는 `frontend/src/App.jsx`의 문자 `p·`, `PayloadLab`과 `workspace.css`의 스타일로 구성됩니다. 이는 기존 UI 표현이며, 독립된 로고 원본 SVG/PNG가 있다는 뜻은 아닙니다. `frontend/src/Icon.jsx`의 아이콘도 브랜드 원본을 대신하지 않습니다.

## 원본이 필요한 작업

로고를 파일로 교체하거나 비율·형태를 유지하며 재사용하려면 다음 자료가 필요합니다.

- 팀이 확정한 원본 SVG, 또는 투명 배경의 충분한 해상도 PNG
- 원본의 작성자·사용 권한과 수정 가능 범위
- 확정된 색상, 밝은/어두운 배경용 변형이 있다면 해당 원본
- 자르기·여백·최소 크기 등 기존 사용 규칙이 있다면 그 기준

원본 확인 전에는 새로운 심볼을 팀 로고로 확정하지 않습니다. 기존 UI 문자 브랜드를 정적 SVG로 충실히 추출하더라도 ‘기존 UI에서 추출한 자산’으로 표시하고, 제공받은 원본이나 새로 승인된 로고와 구분합니다. 이 문서 작업에서는 로고 자산을 생성하거나 교체하지 않았습니다.
