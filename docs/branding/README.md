# 브랜드 원본 확인

연결: [통합 학습 공간 승인 범위](../decisions/2026-10-23-unified-workspace.md)

2026-10-23 현재 저장소의 파일과 상위 로컬 작업 공간에서 `logo` 이름, SVG·PNG·ICO를 조사했으나 팀이 제공한 로고 원본 자산은 찾지 못했습니다. 의존성·빌드 산출물의 이미지는 팀 로고 원본으로 취급하지 않았습니다.

당시 화면의 브랜드는 `frontend/src/App.jsx`의 문자 `p·`, `PayloadLab`과 `workspace.css`의 스타일로 구성되어 있었습니다. 이는 기존 UI 표현이며, 독립된 로고 원본 SVG/PNG가 있다는 뜻은 아니었습니다. `frontend/src/Icon.jsx`의 아이콘도 브랜드 원본을 대신하지 않습니다. 현재 공통 에셋은 아래 승인 기록을 따릅니다.

## 원본이 필요한 작업

팀이 별도로 제작한 정식 로고로 교체하려면 다음 자료를 확인합니다. 아래 승인된 문자 브랜드 파일화에는 이 자료를 선행 조건으로 요구하지 않습니다.

- 팀이 확정한 원본 SVG, 또는 투명 배경의 충분한 해상도 PNG
- 원본의 작성자·사용 권한과 수정 가능 범위
- 확정된 색상, 밝은/어두운 배경용 변형이 있다면 해당 원본
- 자르기·여백·최소 크기 등 기존 사용 규칙이 있다면 그 기준

## 2026-10-24 승인된 문자 브랜드 파일화

사용자가 ‘기존 문자 브랜드를 그대로 파일로 만들기’를 선택했습니다. 기존 `p·` 테두리와 `Payload`/`Lab`의 굵기 구분을 유지한 SVG를 만들었으며 새로운 로고 디자인으로 확정한 것은 아닙니다.

- [라이트 배경용](../../frontend/public/brand/payloadlab-wordmark.svg)
- [다크 배경용](../../frontend/public/brand/payloadlab-wordmark-dark.svg)
- 웹 UI는 테마에 맞는 파일을 선택하고 README는 같은 파일을 `picture`로 사용합니다.
- 두 파일의 형태·크기는 같고 배경에 맞는 글자·테두리 색만 다릅니다. 외부 이미지나 폰트 요청을 포함하지 않습니다. SVG 텍스트는 사용 기기의 글꼴에 따라 세부 모양이 조금 다를 수 있습니다.

팀이 별도 제작한 원본 파일은 여전히 제공되지 않았습니다. 나중에 정식 원본을 받으면 출처·권한을 확인한 뒤 이 공통 에셋을 교체할 수 있습니다.
