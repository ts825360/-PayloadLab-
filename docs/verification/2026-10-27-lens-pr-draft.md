## 본문 초안

일반 이름을 입력하거나 오류·필터·모의 결과를 관찰할 때 입력이 어떤 처리와 비교를 거쳐 결과에 도달했는지 설명이 끊기는 부분을 보완했습니다. 예를 들어 SQL Easy에 박태성을 입력하면 선택한 admin/guest의 이름 비교, 고정된 틀린 비밀번호, AND 조건, 실제 반환0행을 연결해 설명합니다.

### 변경 내용

- SQL: 일반 이름의 따옴표 문자를 OR 누락으로 오해시키는 안내와 실제 문법 오류의 우선순위를 보완합니다. 지원하는 조건식에서는 선택 계정의 비교값·참/거짓·실제 반환을 설명하며, Normal 원문과 필터 사용값을 구분합니다.
- XSS·IDOR: 입력→조립 문장/요청→규칙·소유 관계→실제 결과를 연결합니다. 태그 인식과 실제 브라우저 실행, 주문번호와 소유권 검사, 고정 더미 사용자와 실제 인증을 구분합니다.
- SSRF·CMDi: 실제 연결·셸 실행을 하지 않는 모형의 처리임을 설명합니다. URL 호스트/부분 문자열 정책, 명령 경계/필터 원인, 차단 안내/표준 출력, 미지원 입력을 구분합니다. 이모지 뒤 코드포인트 강조를 올바른 JS 범위로 변환합니다.
- Linux: 입력 토큰·목표·비교 이유와 간략한 가상 출력을 연결합니다. 퀴즈의 고정 순서와 실제 Linux 문법 판정을 혼동하지 않게 설명하고, Linux 개념 패널의 SQL 폴백을 수정합니다.
- 권한 Easy: 명령·대상 파일·현재 사용자에 맞춰 설명하고 읽기 거부·성공·미지원을 구분합니다. exit의 root→student 표시와 입력 앞뒤 공백 처리 설명을 보완합니다.
- 유형별 기존 문안/문제/개선 문안/입력/결과, 기존41개·권한9개 사례, 화면 근거와 검사 로그를 docs에 정리합니다.

기존 실습 목표의 성공 판정과 구현 예정인 권한 Normal 상태를 유지합니다. 창 배치나 Lens를 여는 방식을 새로 설계하는 변경은 포함하지 않습니다.
